# TaskFlow

TaskFlow — полнофункциональное веб-приложение для управления личными задачами.

Проект разработан в рамках производственной практики по специальности 09.02.07 «Информационные системы и программирование».

## Технологии

**Frontend:** React, Vite, JavaScript, CSS

**Backend:** Python, FastAPI, SQLAlchemy

**База данных:** PostgreSQL

**Безопасность:** JWT, хеширование паролей Argon2

**Тестирование:** pytest, HTTPX

## Возможности

- Регистрация пользователей.
- Вход с использованием JWT-токенов.
- Создание, просмотр, изменение статуса и удаление задач.
- Приоритеты задач: низкий, средний, высокий.
- Разграничение доступа: каждый пользователь работает только со своими задачами.
- Поиск и фильтрация задач.
- Статистика выполнения.
- Сохранение данных в PostgreSQL.

## Локальный запуск

### Backend

1. Создать виртуальное окружение Python.
2. Установить зависимости из `backend/requirements.txt`.
3. Создать базу данных PostgreSQL `taskflow`.
4. Выполнить SQL-скрипт `database/schema.sql`.
5. Создать `backend/.env` по примеру `.env.example`.
6. Запустить FastAPI:

```powershell
cd backend
python -m uvicorn main:app --reload
```

Swagger API: http://127.0.0.1:8000/docs

### Frontend

```powershell
cd frontend
npm install
npm run dev
```

Интерфейс: http://localhost:5173

## Тестирование

```powershell
cd backend
python -m pytest tests -v
```

**Примечание:** текущие интеграционные тесты используют базу данных из настроек backend. Для безопасного запуска следует выделить отдельную тестовую базу.

## Безопасность

Пароли пользователей хранятся в виде хешей Argon2. Для доступа к защищённым API используется JWT. Все операции с задачами ограничены идентификатором авторизованного пользователя.

Файл `.env` с конфиденциальными настройками не включается в репозиторий.

## Назначение проекта

Проект используется для демонстрации навыков интеграции программных модулей, проектирования баз данных, реализации API, тестирования и защиты информации.
